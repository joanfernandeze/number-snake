Steps use checkbox (`- [ ]`) syntax for tracking. Implementation subagents run on **Sonnet**; each task is sized for a fresh subagent with zero prior context.

**Goal:** Act on the author's first hands-on playtest of the feel pass (2026-09-08): movement feels clunky (worse on a 60 Hz desktop than on the phone), turns feel late, the body reads as loose blocks, the head is hard to spot, and the walls do not read as lethal.

**Diagnosis:** `main.js` sets `lastTick = now` when a tick fires, so on a 60 Hz display the 200 ms tick lands on frame 13 (217 ms) and the snake stands still for one whole frame every cell — a 5 Hz stutter that also makes it 8 % slower than nominal. On 90/120 Hz phones the pause halves, which matches "phone feels better". Turn latency is the tick boundary (avg. 100 ms) plus a 24 px swipe threshold; the head has no distinguishing mark; walls are drawn like any other edge.

**Architecture:** unchanged. A pure `nextTickTime` helper in `game.js` (tested) gives a fixed-timestep clock; `render.js` gains bridges between segments, a head outline plus eyes that face the *queued* direction (instant acknowledgement of a turn), and a red frame inside the board edge. Two tunables move: `TIMING.tickStartMs` 200 → 170 and `INPUT.swipeThresholdPx` 24 → 16 (spec §14 explicitly leaves these to playtest feel).

**Tech Stack:** unchanged (HTML5 Canvas, vanilla ES modules, `node --test`).

```js
// Clock for the next tick after stepping at `now`. Advancing by one interval (not to
// `now`) lets the leftover time flow into the next slide, so the snake never stands
// still for a frame at each cell. After a long gap (hidden tab) resync to `now`
// instead of fast-forwarding through the missed ticks.
export function nextTickTime(lastTick, interval, now) {
  const next = lastTick + interval;
  return now - next > interval ? now : next;
}
```

### Task 2: Connected body, unmistakable head, red walls

**Files:**
- Modify: `src/render.js`

**Design:**
- Segments are joined by *bridges*: a rectangle the width of a segment body filling the gap between two neighbouring segments, each half in its own segment's colour. Orientation comes from the grid cells (not the drawn pixels) so the bridge stays axis-aligned while the head slides in on an eat tick.
- The head gets a white outline and two eyes on its leading edge. The eyes face `nextDirection(snake)` — the queued turn if any — so a swipe is acknowledged on the very next frame, before the tick applies it. Eyes sit at 0.36 cell forward and ±0.18 cell across, clear of the number.
- A red frame with a soft glow is drawn just inside the board edge, under tiles and snake.

```js
export const PAD = 0.08; // padding around a segment or tile, as a fraction of the cell

// Eye centres relative to the head centre (px) for heading `dir`: on the leading
// edge, spread across it, clear of the number.
export function eyeOffsets(dir, cell) {
  const forward = cell * 0.36, spread = cell * 0.18;
  const px = -dir.y, py = dir.x; // perpendicular to the heading
  return [
    { dx: dir.x * forward + px * spread, dy: dir.y * forward + py * spread },
    { dx: dir.x * forward - px * spread, dy: dir.y * forward - py * spread },
  ];
}
```

Add these functions after `drawNumber`:

```js
// Fill the gap between two neighbouring segments so the body reads as one snake.
// Each half takes its own segment's colour. `vertical` comes from the grid cells, so
// the bridge stays axis-aligned while the head slides in on an eat tick.
function drawBridge(ctx, a, b, cell, colorA, colorB, vertical) {
  const pad = cell * PAD, w = cell - pad * 2;
  const acx = a.px + cell / 2, acy = a.py + cell / 2;
  const bcx = b.px + cell / 2, bcy = b.py + cell / 2;
  const mx = (acx + bcx) / 2, my = (acy + bcy) / 2;
  if (vertical) {
    const x = a.px + pad;
    ctx.fillStyle = colorA; ctx.fillRect(x, Math.min(acy, my), w, Math.abs(my - acy));
    ctx.fillStyle = colorB; ctx.fillRect(x, Math.min(bcy, my), w, Math.abs(my - bcy));
  } else {
    const y = a.py + pad;
    ctx.fillStyle = colorA; ctx.fillRect(Math.min(acx, mx), y, Math.abs(mx - acx), w);
    ctx.fillStyle = colorB; ctx.fillRect(Math.min(bcx, mx), y, Math.abs(mx - bcx), w);
  }
}

function drawHeadOutline(ctx, px, py, cell) {
  const pad = cell * PAD;
  ctx.lineWidth = Math.max(2, cell * 0.06);
  ctx.strokeStyle = 'rgba(255,255,255,0.9)';
  roundRect(ctx, px + pad, py + pad, cell - pad * 2, cell - pad * 2, cell * 0.22);
  ctx.stroke();
}

// Two eyes on the leading edge, pupils nudged forward. `dir` is the direction the
// next tick will take, so a queued turn shows immediately.
function drawEyes(ctx, cx, cy, cell, dir) {
  const r = Math.max(2, cell * 0.075), pupil = r * 0.5;
  for (const e of eyeOffsets(dir, cell)) {
    ctx.fillStyle = '#ffffff';
    ctx.beginPath(); ctx.arc(cx + e.dx, cy + e.dy, r, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#0b1020';
    ctx.beginPath(); ctx.arc(cx + e.dx + dir.x * r * 0.35, cy + e.dy + dir.y * r * 0.35, pupil, 0, Math.PI * 2); ctx.fill();
  }
}

// A red frame just inside the board edge: the boundary is death, say so before contact.
function drawWalls(ctx, L) {
  const lw = Math.max(3, L.cell * 0.07);
  ctx.save();
  ctx.lineWidth = lw;
  ctx.strokeStyle = 'rgba(239,68,68,0.85)';
  ctx.shadowColor = 'rgba(239,68,68,0.9)';
  ctx.shadowBlur = lw * 3;
  roundRect(ctx, L.ox + lw / 2, L.oy + lw / 2, L.cols * L.cell - lw, L.rows * L.cell - lw, L.cell * 0.25);
  ctx.stroke();
  ctx.restore();
}
```

Replace the whole `drawSnake` function with:

```js
// motion.kind: 'slide' = whole body glides from its previous cells (normal move)
//              'grow'  = only the head glides in; the body did not move (eat tick)
//              'none'  = draw at rest (waiting to start, or game over)
function drawSnake(ctx, L, snake, motion) {
  const f = motion.kind === 'none' ? 0 : 1 - motion.progress;
  const dx = -motion.dir.x * f * L.cell, dy = -motion.dir.y * f * L.cell;
  const pos = snake.cells.map((c, i) => {
    const moves = motion.kind === 'slide' || (motion.kind === 'grow' && i === 0);
    return { px: L.ox + c.x * L.cell + (moves ? dx : 0), py: L.oy + c.y * L.cell + (moves ? dy : 0) };
  });
  // Bridges first so the segments paint over their ends.
  for (let i = 0; i < pos.length - 1; i++) {
    const vertical = snake.cells[i].x === snake.cells[i + 1].x;
    drawBridge(ctx, pos[i], pos[i + 1], L.cell, colorFor(snake.values[i]), colorFor(snake.values[i + 1]), vertical);
  }
  for (let i = pos.length - 1; i >= 0; i--) { // tail first so the head paints on top
    drawCell(ctx, pos[i].px, pos[i].py, L.cell, colorFor(snake.values[i]), i === 0);
    drawNumber(ctx, pos[i].px, pos[i].py, L.cell, snake.values[i]);
  }
  const h = pos[0];
  drawHeadOutline(ctx, h.px, h.py, L.cell);
  drawEyes(ctx, h.px + L.cell / 2, h.py + L.cell / 2, L.cell, nextDirection(snake));
}
```
